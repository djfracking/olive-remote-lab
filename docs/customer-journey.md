# Customer journey and product ceiling

## Available now

A customer can:

1. Open the PWA on a phone, tablet or computer.
2. Reconnect automatically to a remembered server or discover one locally.
3. See Now Playing metadata and artwork when the firmware returns it.
4. Browse albums, artists, genres, tracks and playlists.
5. Search the local library.
6. Start a selected track and send verified previous, stop and next commands.
7. Read playlists without risking edits.
8. Add supported music through the server's SMB Import folder.
9. Switch the everyday navigation among English, French, German and Spanish.
10. Export redacted diagnostics when compatibility work is needed.

No account, external server or cloud database is required for this journey.

## High-value next tier

These features are realistic after one safe capture per firmware family:

- play/pause state, elapsed time and duration;
- volume, mute, repeat and shuffle;
- readable queue and queue reordering;
- create/edit playlists and add tracks to them;
- metadata and artwork editing;
- Internet Radio browsing and favorites;
- local UPnP/DLNA source browsing;
- multi-room player selection for Olive companion players;
- library/import progress and server storage health;
- a fully localized content layer rather than translated navigation only.

## Hard boundaries

- Apple Music and Spotify require their own accounts, authorization, internet services and subscriptions. They are optional source adapters, not part of the account-free Olive path.
- Protected streaming audio cannot be copied into the Olive library.
- Spotify can transfer playback only to a recognized Spotify Connect receiver.
- Browser audio cannot be assumed to emerge from the Olive's outputs.
- Destructive library or system commands remain unavailable until their failure and recovery behavior is verified.
- The Olive ONE may require a separate adapter because it is a different platform from Maestro-era servers.

## Product principle

The consumer interface displays only capabilities that work on the connected model. The Protocol Lab may expose explicitly labeled experiments, but the everyday remote never guesses.
