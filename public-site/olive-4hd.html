02

What the remote can—and cannot—do.

The useful boundary is whether a compatible server is running and reachable on the same trusted network.

WHEN THE SERVER IS WORKING

Olive Remote can help

  • Find or manually connect to a reachable O4HD.
  • Browse and search the available local library on tested hardware.
  • Use only commands supported by the current O4HD evidence.
  • Keep server addresses and music metadata on your device.
WHEN HARDWARE HAS FAILED

Olive Remote cannot repair it

  • It cannot make a dead or non-booting server start.
  • It cannot repair a display, power supply, board, or disk.
  • It does not clone, decrypt, recover, or export a library.
  • It does not currently control the separate Olive ONE platform.
  • Volume, queue reading or reordering, playlist editing, metadata editing, destructive library operations, and device settings are not verified.
PRIVATE BY DESIGN

Your library is not a lead list.

The diagnostic asks for model and device state, country, a reply address, your description, and consent. A tagged help path may also include one predefined source label. Do not enter an IP address, serial number, music-library names, or disk contents. A separate optional checkbox controls whether you receive one release email.

COMMON QUESTIONS

Before you begin

Can Olive Remote revive an O4HD that does not boot?

No. It can communicate only with a working, network-accessible server. Use the startup guide to avoid destructive first steps and decide whether hardware help is needed.

Which Olive models are supported?

Only the O4HD is physically verified. Other models are capture-needed. Olive ONE is separate and unverified, so no ONE compatibility is implied.

Can the app recover or export my music?

No. Olive Remote does not recover disks or export libraries. The preservation guide explains safer next steps for working and failed devices.

Can I download the native app now?

The iOS and Android store release is in preparation. You can optionally request one release email in the diagnostic. The source repository remains available for local development.
