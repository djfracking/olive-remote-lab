Export, migration, and failed-disk recovery are different jobs. The safest next step depends on whether the Olive boots, whether the network interface works, and whether another complete copy of the library exists.

FIRST DECISION

Which state describes the server?

It boots and the library plays

This is a migration or backup problem, not failed-disk recovery. Preserve any existing backup, avoid large unrelated changes, and identify model-specific export options before assuming one procedure fits every Olive.

Continue with a working server →

It boots, but behaves inconsistently

Intermittent disappearance, freezes, repeated errors, or unusual sounds raise the stakes. Stop adding or editing music and minimize further use until the storage is assessed.

Continue with an unstable server →

It does not complete startup

This is not an app problem. Avoid factory reset, initialization, or repeated recovery attempts. If the library is unique, prioritize preservation of the original media.

Continue with a failed server →
PATH A · WORKING SERVER

Make a verified copy while access is stable.

  1. 1

    Inventory what already exists

    Check external drives, NAS devices, old computers, and previous exports before changing the Olive. A complete independent copy is the best risk reduction.

  2. 2

    Record the exact model and firmware

    Export and backup behavior may differ. Do not apply instructions written for another model merely because its enclosure or product name looks similar.

  3. 3

    Test a small, reversible sample

    If a documented owner-authorized export path is available for that model and firmware, first verify a small sample away from the only copy. Confirm that audio plays and expected metadata survived.

  4. 4

    Verify the destination

    Compare file counts and sizes, open a representative range of albums, and keep the original unchanged until at least one complete copy has been verified.

PATH B · UNSTABLE SERVER

Reduce activity and preserve options.

Do not continue ripping CDs, editing metadata, importing music, or repeatedly browsing the entire library. Record symptoms, disconnect avoidable workloads, and seek model-aware technical help. A professional may recommend read-only imaging before attempting logical repairs.

PATH C · FAILED SERVER

Recovery starts with the original media.

Ask a qualified specialist

  • Can the original disk be handled read-only?
  • Can a bit-for-bit image be made before repairs?
  • Will work happen on a copy rather than the source?
  • How will bad sectors and imaging errors be logged?
  • What result is realistic before authorizing more work?

Avoid assumptions

  • A successful image is not automatically playable music.
  • A replacement disk does not recover the old library.
  • File-system repair may alter evidence.
  • Firmware files may be model- and version-specific.
  • Consumer cloning tools are not risk-free on failing media.
OLIVE REMOTE BOUNDARY

The controller is not an export or recovery tool.

Olive Remote does not clone disks, decrypt proprietary storage, repair file systems, extract a complete library, or perform destructive library operations. Its physical O4HD testing concerns local connection and core library, search, Now Playing, and front-panel interfaces—not disk recovery—and behavior may vary by firmware. Volume, queue reading or reordering, playlist editing, metadata editing, destructive library operations, and device settings are not verified.

COMMON QUESTIONS

Library preservation questions

Can Olive Remote export my entire library?

No. There is no verified general export function in Olive Remote. The right migration route depends on the exact model, firmware, and condition.

Should I install a replacement disk first?

Not if the original contains the only copy you need. A new disk may help repair the machine later, but it does not preserve the original data. Decide on imaging or professional recovery first.

Can I run a repair utility on the old disk?

Repair tools write changes and may reduce later options. For unique data, the safer pattern is owner-authorized read-only imaging followed by work on a copy.

Does this page promise that every Olive library is recoverable?

No. Results depend on physical condition, file system, model, firmware, prior repair attempts, and storage format. This guide is about reducing avoidable harm.
