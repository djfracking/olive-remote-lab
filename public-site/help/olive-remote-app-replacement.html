BEFORE A REMOTE CAN CONNECT

The server must still be working.

Good candidate

  • The Olive reaches its normal home screen.
  • It is connected to the main home router.
  • The router shows it as a connected device.
  • Your phone or tablet uses the same trusted network.
  • You own and control the device and network.

Needs another path first

  • The server does not power on or finish startup.
  • It clicks, loops, or repeatedly loses power.
  • It is isolated on guest Wi-Fi or behind a VPN.
  • The only concern is recovering files from a failed disk.
  • The device is Olive ONE, which remains unverified.
HOW IT WORKS

Direct control inside your home.

  1. 1

    Join the same trusted network

    The phone or tablet and server must be connected to the main home Wi-Fi or Ethernet LAN. Guest networks commonly block local devices from reaching one another.

  2. 2

    Find or enter the server locally

    Olive Remote first uses local discovery. A manual address is a fallback inside the app; do not post that private address in a forum or diagnostic.

  3. 3

    Confirm the exact model

    Only the O4HD has been exercised against physical hardware. Other models remain capture-needed rather than being assumed compatible from their names.

  4. 4

    Use only evidenced functions

    On tested O4HD hardware, the app can use the core library, search, Now Playing, and front-panel interfaces. Volume, queue reading or reordering, playlist editing, metadata editing, destructive library operations, and device settings are not verified.

This page cannot control your Olive.

A public HTTPS website cannot safely act as a relay into a private legacy HTTP server. The controller must run locally as the native app or, for developers, from the public source repository with the local proxy. Your server traffic and music metadata should stay inside your network.

COMMON QUESTIONS

Remote replacement questions

Can I download the replacement today?

The iOS and Android store release is in preparation. The diagnostic includes a separate optional checkbox for one release email; support replies do not automatically subscribe you.

Does it need an Olive cloud service?

No. The intended connection is directly between your device and compatible Olive server on the same trusted local network.

Will it work with every Olive model?

No such promise is made. The O4HD is the only model tested on physical hardware, and that testing does not establish every O4HD function or firmware. Every other model needs evidence from its real firmware, and Olive ONE requires separate work.

Will this fix a dead server or recover its disk?

No. A remote can control only a running, reachable server. See the startup and preservation guides before attempting repair or recovery.
