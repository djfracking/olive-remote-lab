Privacy without an asterisk.

Olive Remote is designed to operate locally without accounts, analytics, advertising, or a cloud music library.

iOS, Android, and local web applications

Device addresses, discovered service descriptions, request history, protocol logs, settings, and music metadata remain on the phone, tablet, or computer running the application. Native device backup is disabled on Android. The software communicates with private-network music servers selected or discovered by the user.

Public website

The public website contains no analytics SDK, sign-in system, advertising network, cookies, or cross-site tracking. Firebase Hosting necessarily processes ordinary web-server connection data such as IP address and request metadata to deliver the site.

Submission source labels

Some help links contain a predefined source code, such as the name of a public help page or community. During ordinary browsing, the page keeps that code only in the current URL and tagged links; it does not copy it into cookies or browser storage. Like any requested URL, it may appear in ordinary Firebase Hosting request metadata. If you submit the diagnostic form, the code is included with that request so Olive Remote can understand which public resource led to a useful support conversation. The site code does not read raw browser referrers or include them, usernames, profile identifiers, or arbitrary campaign parameters in the diagnostic; ordinary Firebase delivery logs may still contain incoming request-referrer metadata under Firebase’s own logging policies.

Diagnostics

Diagnostics are exported only when the user chooses to create a local JSON file. The exporter redacts likely library names and personally identifying fields. Users should review exported files before sharing them.

Private support and owner diagnostics

The optional support form asks for a reply email address and message, plus optional name and device details. The owner diagnostic asks for model, optional firmware, startup and network state, main problem, country, reply email, and the description you choose to provide. Do not submit IP addresses, serial numbers, credentials, music titles, playlist names, or library metadata. A Firebase Function processes the submission only to deliver it to the private support mailbox through Google’s email service. Olive Remote does not store these requests in an application database. For abuse prevention, the function holds a one-way address hash in short-lived instance memory to enforce an hourly rate limit; it is not placed in the message or an application database. Email providers retain delivered messages under their own policies, and ordinary technical request metadata may appear temporarily in service logs for security and reliability.

Consent and deletion

Reply consent is required and authorizes use of the submitted details only to assess and answer that request. A separate, unchecked option may authorize one email when relevant compatibility testing or store availability opens for that model. It is not a general marketing subscription. You can withdraw that optional permission or request deletion from the support mailbox by submitting a support request from this site.
