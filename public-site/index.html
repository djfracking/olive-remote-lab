WHY NOT RUN THE REMOTE HERE?

The public site is a front door—not a cloud relay.

These servers use local HTTP. Modern browsers intentionally block a public HTTPS page from silently reaching private HTTP devices. Use the native iOS or Android app, or clone the repository and run the local proxy for development. This boundary keeps your library and server traffic inside your network.

SUPPORT
