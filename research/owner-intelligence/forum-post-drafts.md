# Forum posting drafts

Prepared: 18 July 2026

These are starting drafts for manual, affiliation-disclosed participation after the public funnel is deployed and each thread's current rules/open state are checked. Use one useful link per reply. Do not mass-post, automate replies, direct-message participants, or copy the same wording across communities.

## Before any post

1. Read the latest page of the thread and confirm the reported problem is still unresolved.
2. Check vendor, self-promotion, and link rules.
3. Ask a moderator first when creating a standing resource thread.
4. Put the useful answer before the link.
5. Say that Olive Remote is independent and name the exact compatibility limit.
6. Never request an IP address, serial number, firmware file, account information, library names, or member contact details in public.
7. Do not offer firmware downloads until provenance, redistribution rights, model/version fit, hash, and malware status are established.
